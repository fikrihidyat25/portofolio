# React Portfolio (Vite + Tailwind)

A sleek, modern, and responsive portfolio built with React, Vite, Tailwind, and Framer Motion.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build for production
```bash
npm run build
npm run preview
```

## Customize
- Edit texts in `src/components/*`
- Update brand color in `tailwind.config.cjs`
- Replace avatar (🧑‍💻) with your photo in `Hero.jsx`
- Set your email in `Contact.jsx` (mailto or integrate EmailJS/API)
